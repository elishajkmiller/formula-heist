# Formula Heist

A jetpack runner with a physics theme for Android. Licensed GPL-3.0-or-later (see LICENSE).

Build with ./build.sh (no Android SDK or Gradle needed; it fetches its own tools on first run). The signed debug APK lands in dist/formula-heist.apk. A Gradle build is also provided (gradle assembleRelease) for F-Droid.

There is no network access, no ads and no tracking. All art and sound is generated in code.
